# LUMEN AI — AI 비주얼 디렉팅 마스터클래스 & 커머스 웹사이트

> **"상상을 감각적인 비주얼로, AI 비주얼 디렉팅 마스터클래스"**  
> 성인 학습자(직장인, 1인 창업가, 크리에이터)를 위한 생성형 이미지 & AI 비디오 올인원 공식 포트폴리오 & 커머스 원페이지 웹사이트입니다.

---

## 🌟 주요 특징 (Key Features)

- **크리에이티브 스튜디오 톤앤매너**:
  - Obsidian Dark Mode 베이스와 Electric Cyan, Neon Lime, Magenta 포인트 컬러를 조화시킨 미니멀하고 감각적인 다크 테마
  - 모던 글래스모피즘(Glassmorphism) 및 은은한 백드롭 블러 효과 적용
- **100% 단일 파일 완성형 (Single-Page App)**:
  - HTML5, Tailwind CSS CDN, Lucide Icons, Pretendard 웹폰트를 활용하여 추가 빌드 과정 없이 즉시 브라우저에서 실행 가능
- **인터랙티브 기능**:
  - **Before & After 비교 슬라이더**: 초보자의 단순 프롬프트 결과와 디렉터의 마스터 라이팅 결과물을 왜곡 없이 좌우로 드래그 비교 (`clip-path` 기술 적용)
  - **VOD & 전자책 주문 모달**: 결제 수단 선택 및 수강생 정보 입력을 통한 즉시 주문 및 자동 이메일 발송 피드백 시뮬레이션
  - **클래스 미리보기 티저 모달**: 챕터별 커리큘럼 아웃라인과 4K 60fps 재생 시뮬레이션
  - **포트폴리오 고해상도 라이트박스**: 카테고리 필터링(전체, 패션/룩북, 시네마틱/SF, 제품/커머스, AI 모션) 및 상세 뷰
  - **출강 및 상담 접수 폼**: 즉시 확인 가능한 토스트(Toast) 알림 및 피드백 인터랙션
  - **모바일 완벽 반응형**: 모바일 전용 햄버거 메뉴 및 장바구니 카운트 배지 지원

## 🚀 로컬 실행 방법 (How to Run)

### 방법 1. 브라우저에서 바로 열기
`index.html` 파일을 더블 클릭하거나 웹 브라우저(Chrome, Edge, Safari 등)로 드래그 앤 드롭합니다.

### 방법 2. 로컬 웹 서버 실행 (Python)
```bash
# 프로젝트 디렉터리에서 실행
python -m http.server 8080
```
브라우저에서 `http://localhost:8080`으로 접속합니다.
